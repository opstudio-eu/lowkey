# Lowkey 0.10.2

## Improved

- Fewer synchronous requests to the app while typing. Suggestion updates reuse
  one text snapshot and avoid restarting identical work.
- Space and punctuation no longer run a spelling search on the input thread.
  If a correction is not ready, the word stays as typed instead of making the
  next key wait. Ready corrections and immediate Backspace undo still work.
- Overlapping taps with two thumbs keep their press order, including reversed
  releases and two fingers on the same key. An already open accent or number
  popup stays independent; starting another tap accepts an earlier pending tap.
- Obsolete suggestion searches stop sooner, and suggestion changes reuse the
  keyboard layout.

Tests in a deliberately slow emulator editor showed fewer editor queries and
lower median text-change latency. Occasional latency spikes were not eliminated;
these results do not measure performance on every phone or app.

## Updating

Install the signed `lowkey.apk` over the existing Lowkey app, or use
**Settings → Updates → Check now**. Settings, languages, downloaded models and
the personal dictionary remain in place.
