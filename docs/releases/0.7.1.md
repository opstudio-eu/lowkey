# Lowkey 0.7.1

## Fixed

- Select the keyboard you want directly from Languages & layouts. The chosen language and letter layout are remembered.
- Turn off a language and all its layouts with one switch. English (US) can be turned off too; its built-in word list remains available without appearing in the keyboard switcher.
- Choose an enabled layout from Keyboard in use on the layouts page, without opening the keyboard first.
- Removing a downloaded word list now asks for confirmation. The last active language stays on until another language is enabled.

## Updating

Install the signed APK over your existing Lowkey app. Your settings, downloaded languages, speech models and dictionary are preserved.
