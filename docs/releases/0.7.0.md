# Lowkey 0.7.0

## Changed

- A calmer English interface with four clear destinations: Home, Voice, Dictionary and Settings.
- Home shows the keyboard's actual setup state. Voice and photo access are optional; typing works without them.
- Settings are grouped by task. Size and position, automatic split, the number row, the key beside Space and all existing preferences remain available.
- Voice groups multilingual and English-only models, with clear download, progress, cancel, retry and selection actions.
- Dictionary makes saved words and speech rules easier to find, edit and delete. Inactive speech rules show why they do not apply.
- Refined OpStudio styling, a short opening transition and layouts that accommodate large text.

## Updating

Install the signed `lowkey.apk` over the existing Lowkey app. Settings, keyboard placement, downloaded models, language packs and the personal dictionary stay in place. **Settings → Updates → Check now** also finds the update.

The separately named UI Preview is a test app with its own data. Production updates are offered only by the regular Lowkey app.
