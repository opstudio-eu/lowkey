# Lowkey 0.9.0

## Added

- Hold the emoji key to switch keyboard language. A row of your enabled languages and layouts opens over the key, the way accents do: slide to one and let go. If you let go without sliding, the row stays open so you can tap a language; tap elsewhere or press Back to close it. A tap still opens emoji, and a small corner mark shows the key can be held. With only one keyboard (language and layout) enabled, the key works as before.

## Updating

Install the signed `lowkey.apk` over the existing Lowkey app, or use **Settings → Updates → Check now**. Settings, languages, downloaded models and the personal dictionary remain in place.
