# Lowkey 0.6.0

## Added

- Resize the keyboard directly with handles, including its width, and move it to a comfortable position.
- Choose one-handed, floating or split mode from the keyboard's quick menu. Split mode can be enabled automatically on wide screens and shares the middle keys between both thumbs.
- Turn a dedicated number row on or off in Settings.
- Insert emoji offline using categories, recent choices and skin-tone variants. Hold the comma to open emoji, or use the optional emoji key beside Space.

## Changed

- Hold Space to open Android's keyboard switcher directly. Settings can restore the language key beside Space for cycling through Lowkey layouts.
- Keyboard size, position and mode are remembered separately for compact and large windows in portrait and landscape.
- Recent screenshots are enabled by default once access to all photos is granted. Home shows the photo-access setup step, and Settings explains limited photo access.

## Updating

Install the signed `lowkey.apk` from this release over the existing Lowkey app. Settings, downloaded models and the personal dictionary stay in place. In Lowkey, **Settings → Updates → Check now** also finds the update.

The separately installed Lowkey Demo remains a separate app. The production app uses its own settings and data.
