# Lowkey 0.6.1

## Fixed

- The minimized keyboard bar stays at the bottom, above Android's navigation area, even after moving the full keyboard upward. Expanding restores the saved keyboard size and position.
- Floating mode no longer leaves space for a drag handle below the minimized bar.

## Updating

Install the signed `lowkey.apk` from this release over the existing Lowkey app. Settings, downloaded models and the personal dictionary stay in place. In Lowkey, **Settings → Updates → Check now** also finds the update.
