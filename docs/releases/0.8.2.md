# Lowkey 0.8.2

## Fixed

- Android's input-method menu now shows one Lowkey Keyboard entry. The old fixed English and Dutch entries could remain selectable after those languages were turned off in Lowkey.
- Lowkey keeps the language and layout selected in Languages & layouts when you switch back to it from another keyboard app. Language switching within Lowkey still uses your enabled layouts.

## Updating

Install the signed APK over your current Lowkey app. Your languages, layouts, settings and dictionary are kept. Other keyboard apps, such as Gboard, manage their own language entries.
