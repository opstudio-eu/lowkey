# Lowkey 0.6.2

## Fixed

- Recent screenshots and clipboard history now appear in the full keyboard's top strip whenever no word is being typed, just like on the minimized bar. This also works with the suggestion strip turned off.
- A sensitive copied item, such as a password, no longer hides the history. It stays available as a masked **Copied text** chip at the start of the strip. Password fields still show no history.

## Updating

Install the signed `lowkey.apk` from this release over the existing Lowkey app. Settings, downloaded models and the personal dictionary stay in place. In Lowkey, **Settings → Updates → Check now** also finds the update.
