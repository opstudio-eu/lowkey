# Lowkey 0.12.0

## Changed

- A calmer welcome and setup flow, with clear confirmation when the keyboard is enabled and one remaining step to select it.
- A compact Lowkey header and more consistent settings pages. Related options are grouped together, with optional explanations behind expandable rows.
- Voice setup now follows a checklist: allow the microphone, download a speech model, then try dictation. Model selection, download progress, cancellation and model management remain available.
- Your installed keyboard languages appear first. Add more through **Add a language**, and tap a language to use it.
- The keyboard test has a simpler field and a clear icon. Additional editor types remain under **Settings → Try it**.
- The theme editor keeps its save actions within reach and asks before discarding unsaved changes when leaving or switching to Standard.

## Fixed

- Choosing another speech model no longer makes an already working voice setup appear incomplete.
- Text in the advanced Android test field survives collapsing and reopening it; **Clear all fields** clears it too.
- Storage details remain readable with larger system text. The theme illustration retains its proportions without clipping its labels.

This update preserves your settings, saved words and downloaded models. Speech still runs on your phone after the model download; voice setup is optional.
