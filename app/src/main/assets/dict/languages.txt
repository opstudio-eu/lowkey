# Keyboard languages. Adding one is a data change: add a section here, then (for a bundled language)
# run scripts/build-dictionaries.py. The app and that script both read this file.
#
# Every word list comes from the AOSP LatinIME dictionaries (Apache-2.0) at one pinned commit:
# <source>/<id>_wordlist.combined.gz, checked against `sha256` (of the .gz file) and `size` (its bytes).
#
# Section keys:
#   name     the language's own name, shown on the space bar and in Settings
#   english  its English name
#   short    two- or three-letter label
#   speech   Whisper language code used by "Voice language: Same as keyboard" (empty: auto-detect)
#   rows     the three letter rows, separated by spaces; letters only, any script
#   accents  long-press choices offered first, as letter:choices (the general accent list follows)
#   bundled  true: shipped in the APK as dict/<id>.dict; false: downloaded on request
#   accent_margin  optional: autocorrect a known word typed without accents to its accented form
#            when that is this much more frequent (0-255 scale). Only for languages whose word list
#            also holds accent-less spellings of common words (Polish `juz` next to `już`).
#   capitalized_nouns  optional, true for languages that capitalize nouns (German): `zeit` -> `Zeit`.

source = https://android.googlesource.com/platform/packages/inputmethods/LatinIME/+/127336e9f29d69607eab55982324b210279ae8c5/dictionaries
